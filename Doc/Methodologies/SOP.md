# 找idea思路

## 一、从用户问题寻找机会

角度：用户角度出发，关注他们目前的需求。

核心思路：非常垂类 niche 可以从人本身的欲望想法出发 最好这个需求能够切中人们想要主动分享的欲望。

路径：Reddit、Quora (国外知乎）知乎 小红书用户讨论、Upwork、Fiverr （外包平台 主要在seller售出服务 看人家在卖什么 多不多人买 怎么卖）Gumroad Etsy Indiehackers

思考什么问题：用户在求助什么、外包什么、抱怨什么；目前用了哪些办法，付出了什么

方法：让ai或者其他工具 找出reddit quora

a. 哪个话题最多人加入（帖子最多） 列出100个 如果没发现我们要的 继续列出接下来的200个

b. 这些帖子里说的主要话题是什么 有没有人在投诉 寻求帮助 他们需要什么 有没有急需解决的？

c. 这些帖子里有没有提到一些解决的方案 有没有产品？

d. 如果有产品 重点看他们的优点和缺点在哪里 客户投诉什么？客户夸赞什么？客户有没有提建议？（如果这产品能做xxx就好了）

e. 在过去的90天 reddit quora 用户最多聊的是什么话题？热点在哪里？

F. 加入这些话题 访问客户 conduct interviews, run surveys, 加入他们 建立信任 建立authority as an expert in this industry

Upwork (外包平台 主要看谁在提出需要并且愿意付费 证明市场需求和付费意愿和产品某方面的缺失）

A. 去竞标 提出最便宜的价格 或者免费 换取客户的interviews

B. 看具体需求和解决方案 他们愿意付多少钱 其他人竞价大概是多少钱的区间 （这项产品大概值多少钱？）

C. 发掘有人想外包 但是市场上没有现成的产品

D. 发掘市场上有产品 但是功能不齐全 没法满足客户的需要

Gumroad Etsy

A.哪个虚拟产品卖得最好

B。哪个容易复制

c.抄 卖 免费送

IndieHackers

开发者论坛都在说什么

Kickstarter Indiegogo

A. 虚拟产品哪个众筹的销量多

B.哪个品类最近180天卖超过50000

## 二、从已有产品寻找切入点（低垂果实法）

角度：从已有市场的生意反推

核心思路：从已有的市场的产品去抄 去学习他们的产品思路。价格高的，能不能低价竞争。

路径：Acquire、Flippa、Product Hunt、AppSumo、trustmrr Kickstarter IndieGogo
思考什么问题：产品服务谁、解决什么问题、怎么收费；客户为什么购买，又对哪里不满意

Acquire Flippa TrustMRR

A. 哪个赛道的生意能卖好价钱 什么样的模式 更受买家喜欢

B. 这些生意的竞争者有谁？这个赛道是怎么赚钱的 他们怎么获客 他们的客户画像 网站和landing pages怎么是怎么样的风格，关键词是什么 我需要他们网站的截图 作为参考和调研

C.尝试竞争对手的产品 记录他们的销售流程 漏斗 话术 价格 email subscriptions

D. 他们的风评如何 网上的人怎么说 在推特上面 搜索他们的名字 风评网站怎么说

E. 用seo tools审计他们的seo策略

F. 用ppc工具窃取他们买广告的关键词

G. 他们一天的流量有多少

F. 用爬虫把他们的一切信息搜出来

Product Hunt Appsumo

A. 过去一年 卖最多items的产品是什么 销量最高的是哪个产品

B. 过去历史 哪个卖最多单量 哪个卖最高销量

C. 过去一年 哪个领域/赛道卖的产品 最多单量 最多销量

D. 他们成功的launch strategy是怎样的 怎么成功 找的哪个机构 用的什么方法

## 三、从搜索与趋势发现线索

角度：从搜素和市场趋势切入
核心思路：看目前市场上人们关注的热点是什么
路径：Google trends, Google Search、Google Ads 、 Sensor Tower Appstore AndroidPlay

思考什么问题：用户用什么词寻找什么解决办法、搜素的热度以及相关的产品趋势如何。

Google Trends

1. 过去30 90 180天的热点是什么

2. 我们要投入的赛道 最近的话题度 高不高

3. keywords是什么

关键词调研

1. Buyer's keywords是什么

2. 竞争者花多少钱买广告 广告第一名的bidding cost是多少 一天能有多少clicks

Sensor Tower, AppStore Playstore

1.每个category的前50名是什么产品

2. 这些前50名产品以内 有多少是重叠的 具体是什么类型的

3. 这些前50名以内的产品 哪个值得我们去做

4. 这些前50名产品 他们的正面和负面客户反馈是什么

# 问题分析

通过以上途径找到了针对于觉得可行的方向或idea后 需要研究以下问题

|                |                                                                  |
| -------------- | ---------------------------------------------------------------- |
| 分析项         | 要回答的问题                                                     |
| 用户与场景     | 谁在什么情况下遇到问题？谁使用，谁决定购买？                     |
| 问题与代价     | 问题多久出现一次？带来什么时间、金钱或其他具体影响？             |
| 现有解决办法   | 用户现在靠软件、人工还是外包完成？为什么采用这个办法？           |
| 商业线索       | 有什么报价、预算、交易评价或收入披露？分别来自谁，核实到哪一步？ |
| 潜在切入点     | 哪个具体场景仍然处理不好？我们可能改善哪一步？                   |
| 客户与交付条件 | 第一批潜在用户在哪里？我们能否完成一次最小交付？                 |
